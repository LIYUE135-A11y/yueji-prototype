# 社区管理内容填充计划

## 研究结论

1. **当前状态**：社区管理面板已存在 5 个选项卡（文章/种草/圈子/话题/动态），但每个 tab 都是空的占位内容
2. **已有基础设施**：
   - tab-bar / tab-content CSS 已就绪（带紫色渐变激活效果）
   - `USER_AVATAR_MAP` 和 `getUserAvatar()` 函数已存在，使用本地 `avatars/` 目录
   - 所有模块的操作按钮已改为链接样式，统一风格
3. **图片来源问题**：`text_to_image` API 返回的所有图片都是相同占位图（MD5 一致），必须使用其他方案

## 解决方案

### 图片下载方案
- 使用 `picsum.photos` 免费占位图 API，通过不同 seed 参数生成**真正不同**的图片
- 下载 25 张内容图 + 10 张头像图，存储在本地 `community_images/` 目录
- 文章配图：`article_1.jpg` ~ `article_5.jpg`
- 种草配图：`grass_1.jpg` ~ `grass_5.jpg`
- 圈子配图：`circle_1.jpg` ~ `circle_5.jpg`
- 话题配图：`topic_1.jpg` ~ `topic_5.jpg`
- 动态配图：`feed_1.jpg` ~ `feed_5.jpg`
- 头像图：`avatar_*.jpg` 共 10 张

### 内容设计
每个 tab 有完全不同的内容：

| Tab | 类型 | 内容特点 |
|-----|------|---------|
| 文章管理 | 文章列表 | 标题、作者、封面、分类、阅读量、评论数、状态 |
| 种草管理 | 种草帖子 | 用户分享、图片、心得、点赞/收藏/评论数 |
| 圈子管理 | 圈子列表 | 圈子名称、头像、成员数、帖子数、圈主 |
| 话题管理 | 话题列表 | 话题标签、发起人、参与人数、讨论数、热度 |
| 动态管理 | 动态信息流 | 用户动态、图片、文字内容、点赞/评论/转发 |
